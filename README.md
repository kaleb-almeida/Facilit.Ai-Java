# Facilit.Ai - Java

> Projeto final do curso de **Formação de Tecnologia**.

</div>

O **Facilit.AI** é uma solução inteligente desenvolvida como projeto do curso de **Formação de Tecnologia**. O objetivo principal é auxiliar o usuário nas demandas do dia a dia através de **4 IAs especializadas** focadas nos pilares da vida adulta:

* 💼 **Trabalho:** Suporte na rotina profissional, e produtividade.
* 💰 **Finanças:** Orientações sobre planejamento financeiro, orçamento e controle de gastos.
* 🧠 **Saúde Mental:** Dicas de bem-estar, acolhimento, organização pessoal e equilíbrio, que não substitui uma pessoa real.
* 🎓 **Educação:** Auxílio nos estudos, pesquisas, e planos de aprendizado.

---

### 🔥 Diferencial

Sabemos que nem todo mundo consegue formular um *prompt* completo ou perfeito de primeira. 

Quando o usuário envia um prompt considerado **"ruim"** (vago, sem contexto ou incompleto), a IA do **Facilit.AI** faz perguntas investigativas ao usuário para extrair os detalhes necessários. Assim, ela garante que a resposta final seja extremamente assertiva e personalizada.

Deixamos as IAs especificas em suas respostas, fazendo o usuario não precisar fazer um prompt gigante, e se o usuario tentar desviar o assunto, a IA retornara.

---

### O que Contem

Este Repositorio contem a logica Java para o Sistema de Login e Cadastro, e o armazenamento das conversas e dos usuarios no Banco de Dados, que foi usado o MySQL.

## ⚙️ Como Executar o Projeto

1. **Banco de Dados:**
   * Garanta que o **MySQL** esteja instalado e em execução.
   * Crie o banco com as tabelas `usuario` e `mesagens`.

2. **Servidor:**
   * Importe o projeto no **Eclipse IDE**.
   * Configure e inicie o projeto usando o **Apache Tomcat**.
